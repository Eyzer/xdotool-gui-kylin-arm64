# xdotool-gui — 输入自动化助手（Qt5 / 银河麒麟 arm64）

上游项目：https://github.com/jordansissel/xdotool
本包 = 上游 libxdo（xdotool 核心库，版本 4.20260303.1）静态链接 + 自研 Qt5 图形界面。

---

## 一、交付物

| 文件 | 说明 |
|---|---|
| `out/xdotool-gui_1.0.0-1_arm64.deb` | 可安装的 arm64 软件包 |
| `out/shots/*.png` | 在 arm64 环境下实机运行截图 |
| `src/main.cpp` | Qt5 图形界面源码（单文件） |
| `src/xdotool-gui.pro` | qmake 工程文件 |
| `deb/control` `deb/postinst` | Debian 打包元数据 |
| `assets/` | 桌面图标与 .desktop 启动项 |
| `scripts/` | 完整可复现的构建 / 验证脚本 |

包内安装内容：

- `/usr/bin/xdotool-gui` — Qt5 图形主程序
- `/usr/bin/xdotool-gui-cli` — xdotool 命令行（静态链接，不依赖 libxdo.so）
- `/usr/share/applications/xdotool-gui.desktop` — 开始菜单项
- `/usr/share/icons/hicolor/scalable/apps/xdotool-gui.svg` — 图标

---

## 二、目标系统要求

- 银河麒麟桌面操作系统 V10（arm64 / aarch64）
- 内核 5.4.18 及以上
- Qt5 运行库（`libQt5Widgets.so.5`、`libQt5Gui.so.5`、`libQt5Core.so.5`，5.12 或更高）
- X11 桌面会话
- 二进制最低 glibc 符号需求仅为 **GLIBC_2.17**，兼容所有 arm64 麒麟版本

---

## 三、安装

将 deb 复制到麒麟机器，在终端执行：

```
sudo dpkg -i xdotool-gui_1.0.0-1_arm64.deb
sudo apt-get -f install        # 仅在提示缺依赖时执行
```

安装后可在开始菜单搜索「输入自动化助手」，或终端执行：

```
xdotool-gui
```

卸载：

```
sudo dpkg -r xdotool-gui
```

## 四、功能

**作用目标（顶部）**：可选「当前活动窗口（全局 XTest 注入）」或指定窗口 ID。
后者使用 XSendEvent，部分应用会忽略；日常使用请保持默认的当前活动窗口。

**鼠标页**
- 绝对移动（含多屏选择）、相对移动
- 读取指针当前位置
- 左/中/右键、滚轮上下、前进/后退键的点击（可设重复次数与间隔）
- 鼠标键按下 / 抬起（用于拖拽）

**键盘页**
- 文本自动键入（可调字符间隔，适合填入表单 / 密码框）
- 按键序列发送：`ctrl+c`、`alt+Tab`、`super+d`、`F5`、`shift+Insert` 等
- 按键按下 / 抬起（用于组合键长按）
- 22 个常用快捷键一键按钮

**窗口页**
- 按标题正则、类名正则搜索窗口（可限定搜索深度、结果上限）
- 结果表显示窗口 ID / 标题 / 类名 / PID
- 激活、聚焦、置顶、降低、最小化、关闭、强制结束、映射、取消映射
- 窗口移动到指定坐标、调整尺寸（可选终端字符网格 SIZE_USEHINTS）
- 读取窗口信息（标题、类名、位置、尺寸、PID）

**其他页**
- 毫秒级延时（便于编排操作节奏）
- 虚拟桌面数量读取 / 修改、切换桌面
- 运行日志（所有操作返回码，可复制）

## 五、注意事项

1. **必须运行在 X11 会话下**。银河麒麟 V10 桌面版 UKUI 默认即 X11，可正常使用。
   若系统运行在 Wayland 会话，XTest 输入注入不生效，鼠标键盘功能将无效。
   可用 `echo $XDG_SESSION_TYPE` 确认，返回 `x11` 即可。
2. 退出后置顶 / 最小化等窗口操作依赖窗口管理器 EWMH 支持，麒麟 UKUI 支持良好。
3. 无窗口管理器的裸 X 环境下会提示 `_NET_ACTIVE_WINDOW` 不受支持，属正常现象。
4. 本包不安装 / 不覆盖系统的 `xdotool` 命令，命令行入口独立命名为 `xdotool-gui-cli`，避免冲突。

## 六、验证记录（arm64 环境实测）

构建方式：Ubuntu 20.04 arm64（glibc 2.31）chroot + qemu-user-static 全量编译，
Xvfb 虚拟 X 服务器实机运行本包。

| 验证项 | 结果 |
|---|---|
| deb 安装（dpkg -i） | 通过 |
| 图形界面启动、4 个页签渲染、中文显示 | 通过 |
| XTest 扩展探测 | 通过（XTest 2.2，上游 `xdo_has_feature` 存在位掩码缺陷，本程序改为直接探测扩展） |
| 鼠标绝对移动 `200,200` | 通过，读回一致，xev 收到 MotionNotify |
| 鼠标相对移动 `+50,+50` | 通过，读回 `250,250` |
| 鼠标点击注入 | 通过，xev 收到 ButtonPress |
| 由注入点击驱动界面切换 4 个页签 | 通过，四页画面差异 13.5 万 ~ 28 万像素 |
| 键盘序列注入 | 通过，返回码 0 |
| 文本键入 | 通过，返回码 0 |
| 窗口搜索 / 窗口管理 | 通过（Xvfb 无窗口管理器，EWMH 类操作跳过） |
| 动态依赖 | 仅 Qt5 + libX11/libXtst/libXinerama/libxkbcommon，无 libxdo |
| glibc 符号需求 | GLIBC_2.17（arm64 最低基线） |

截图位于 `out/shots/`：`p0.png`（鼠标）、`p1.png`（键盘）、`p2.png`（窗口）、`p3.png`（其他），
均为 arm64 环境下实机运行、由注入点击逐页切换后抓取。

## 七、重新构建

在 x86_64 Debian 主机上（需联网、需 root）执行 `scripts/build_all.sh`
即可从零复现：安装 debootstrap + qemu-user-static → 构建 arm64 根文件系统 →
安装 Qt5 交叉依赖 → 编译 libxdo.a 与 Qt5 界面 → 打包 deb。
随后执行 `scripts/build3.sh` 完成静态 CLI 打包与端到端验证。
