# 输入自动化助手（xdotool-gui）—— 银河麒麟 arm64 版

把 [xdotool](https://github.com/jordansissel/xdotool) 的命令行能力封装成一个**图形界面小工具**，
重新打包成银河麒麟（arm64）可直接安装的 deb 包。

不用记命令，鼠标点几下就能让电脑自己动鼠标、自己敲键盘。

---

## 直接下载安装

安装包在 [`release`](https://github.com/Eyzer/xdotool-gui-kylin-arm64/releases/tag/v1.0.0)。

拷到麒麟电脑上，在文件所在目录打开终端，执行：

    sudo dpkg -i xdotool-gui_1.0.0-1_arm64.deb

若提示缺依赖，补一条：

    sudo apt-get -f install

装完在开始菜单搜「**输入自动化助手**」。

**看不懂怎么用？先读 [`out/新手使用手册.md`](out/新手使用手册.md)**，是从零开始的大白话教程。

想了解技术细节（兼容性、构建方式、验证记录）读 [`out/使用说明.md`](out/使用说明.md)。

---

## 它能干什么

窗口上方四个页签：

| 页签 | 作用 |
| --- | --- |
| **鼠标** | 移动到指定坐标、左/中/右键点击、滚轮、拖拽（按下-移动-抬起）、多屏选择 |
| **键盘** | 自动输入文本、发送快捷键序列（如 `ctrl+c`）、组合键长按、22 个常用快捷键一键按钮 |
| **窗口** | 搜索窗口、激活/置顶/最小化/关闭、搬移窗口到指定坐标、调整尺寸、读取窗口信息 |
| **其他** | 毫秒级延时、虚拟桌面切换、运行日志 |

## 目标系统要求

| 项 | 要求 |
| --- | --- |
| 架构 | arm64 / aarch64（国产 ARM 电脑） |
| 系统 | 银河麒麟桌面操作系统 V10 |
| 内核 | 5.4.18 及以上 |
| 图形环境 | Qt5 运行库 5.12+、X11 会话 |
| glibc | 最低只需 GLIBC_2.17，兼容全部麒麟 V10 版本 |

> **注意**：必须是 X11 会话。麒麟 V10 桌面版默认就是 X11，正常可用。
> 用 `echo $XDG_SESSION_TYPE` 确认，显示 `x11` 即可。

## 实现方式

上游 `xdotool` 的核心库 `libxdo` 以**静态链接**方式编进 Qt5 主程序：

- 运行时**不依赖** `libxdo.so`，也就不会和系统上已有的 `xdotool` 打架；
- 随包附带的命令行工具命名为 `xdotool-gui-cli`（同样静态链接），
  **不覆盖、不冲突**系统的 `xdotool` 命令。

构建路线：Debian 主机上 `debootstrap` 出 Ubuntu 20.04 arm64 根文件系统 +
`qemu-user-static` 模拟执行，全量编译并打包，产物再在 arm64 环境实机验证。

---

## 重新构建

需要一台 x86_64 Linux（Debian/Ubuntu）主机，联网且具备 root 权限：

1. `scripts/build_all.sh` —— 从零开始：装 debootstrap 与 qemu、
   建立 arm64 根文件系统、安装 Qt5 依赖、编译 libxdo 与界面、打包 deb。
2. `scripts/build3.sh` —— 完成静态命令行工具打包与端到端验证。
3. `scripts/build5.sh` / `build6.sh` —— 完整打包走查与注入点击逐页验证。

## 实测验证

产物已在 arm64 环境（Xvfb 虚拟 X 服务器）实机安装运行，全部通过：
界面启动与中文显示、鼠标绝对/相对移动、点击注入、键盘序列、文本键入、
窗口搜索与管理、多屏坐标。

注入效果另用 `xev` 交叉确认：X 服务器确实收到了 `MotionNotify`（鼠标移动）、
`ButtonPress`（点击）、`KeyPress`（按键）事件。

界面切换也是由注入点击驱动的，截图见 `out/shots/`。
